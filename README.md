# دفتر المدرس الذكي — نسخة Native (Kotlin + Jetpack Compose)

هذا مشروع Android Studio حقيقي (Kotlin 100%، بدون أي WebView)، يعيد بناء التطبيق الأصلي خطوة بخطوة.

## كيف تفتحه وتشغّله
1. افتح Android Studio (أحدث إصدار مستقر).
2. File → Open → اختر مجلد `SmartTeacherNative`.
3. انتظر مزامنة Gradle (يحتاج إنترنت أول مرة لتحميل المكتبات).
4. اضغط Run ▶ على جهاز حقيقي أو محاكي.

## ما تم إنجازه في هذه المرحلة (Phase 1)
- **طبقة بيانات كاملة (Room)**: تطابق تماماً بنية البيانات في ملفك الأصلي
  (مدارس، صفوف، طلاب، حقول مخصصة، سجلات مشاركة/واجب/دفتر/سلوك، حضور وغياب، درجات، جدول حصص).
  هذا أهم وأصعب جزء، وهو الأساس الذي تُبنى عليه بقية الشاشات.
- **تصميم مطابق للألوان الأصلية** (الأخضر #00695c، البرتقالي، إلخ) عبر Jetpack Compose + Material 3.
- **قسم "الصفوف" يعمل بالكامل**: إضافة/حذف مدرسة → إضافة/حذف صف → إضافة/حذف طالب (محفوظ محلياً في SQLite عبر Room، بديل localStorage).
- شريط تنقل سفلي بنفس الأقسام الخمسة الأصلية (الإعدادات، الإحصائيات، الخطط، الجدول، الصفوف).

## ما تبقى (المراحل القادمة)
1. **شاشة تفاصيل الطالب**: المشاركة، الواجبات، الدفتر، السلوك، الحقول المخصصة، تقويم الحضور، الدرجات والمعدل.
2. **الجدول**: الجدول الأسبوعي للحصص + جدول الامتحانات.
3. **الحصص**: التقويم الشهري لعدد الحصص لكل مدرسة.
4. **الخطط**: الخطة اليومية والخطة السنوية.
5. **الإحصائيات**: التنبيهات (رسوب، تفوق، تحسّن، غياب متكرر).
6. **الإعدادات**: نسخ احتياطي/استعادة (تصدير واستيراد JSON)، تفعيل الاشتراك (يحتاج ربط بنفس الخادم المستخدم في النسخة الأصلية).
7. **تصدير PDF** للتقارير (مكتبة مثل iText أو Android PdfDocument).
8. أيقونة التطبيق (Image Asset Studio في Android Studio) — حالياً تستخدم الأيقونة الافتراضية.

> ملاحظة: بما أن بيئة المحادثة لا تملك اتصال إنترنت ولا Android SDK، لم يتم بناء/تجربة الكود فعلياً هنا — إذا واجهت أي خطأ بسيط عند المزامنة في Android Studio، أرسل لي رسالة الخطأ وأصلحه فوراً.
